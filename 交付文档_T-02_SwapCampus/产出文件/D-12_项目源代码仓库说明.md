分支：`main`

## 1. 仓库结构

```text

```

## 4. 启动方式

全套 Docker 启动：

```powershell
docker compose --profile app up -d --build
```

仅启动基础设施：

```powershell
docker compose up -d
```

本机启动后端：

```powershell
cd backend
mvn spring-boot:run
```

本机启动前端：

```powershell
cd frontend
npm install
npm run dev
```

## 6. CI/CD

GitHub Actions 工作流位于：

```text
.github/workflows/ci.yml
```

每次 push 或 PR 会执行：

- 后端 Maven 测试与 JaCoCo 报告。
- 前端 npm ci 和生产构建。
- push 到 main 时执行 Docker 镜像构建检查。

## 7. 提交规范

提交信息优先中文说明，可保留英文类型前缀：

```text
feat: 完成用户登录接口
fix: 修复订单状态流转校验
docs: 更新 Docker 一键启动说明
test: 增加支付 Mock 单元测试
```

## 8. 归档建议

最终提交时建议包含：
