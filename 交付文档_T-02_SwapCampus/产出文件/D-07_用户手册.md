## 3. 买家操作

### 3.1 登录

1. 打开前端首页。
2. 进入登录页。
3. 输入买家账号和密码。
4. 登录成功后进入商品浏览页面。

### 3.2 浏览和搜索商品

1. 在首页查看北林绿色信息流中的推荐商品。
2. 使用关键词搜索教材、数码、生活用品等。
3. 使用分类、价格、成色等筛选条件缩小范围。
4. 点击商品卡片进入详情页。
5. 进入浏览历史页面，可查看最近浏览过的商品并返回详情页。

### 3.3 收藏和聊天

1. 在商品详情页点击收藏。
2. 点击联系卖家，进入聊天页面。
3. 在会话列表和聊天顶部确认商品名称、封面图与价格。
4. 发送文本、图片或表情消息，与卖家协商交易。

### 3.4 下单与支付

1. 在商品详情页点击立即下单。
2. 确认交易方式。
3. 进入订单详情页，确认商品图片、名称、金额和交易方式。
4. 完成模拟支付。
5. 等待卖家确认订单。

### 3.5 确认收货与评价

1. 面交或柜机取件后，在订单详情页确认收货。
2. 订单完成后提交评价。
3. 查看信用分变化记录。

## 4. 卖家操作

### 4.1 发布商品

1. 登录卖家账号。
2. 点击发布商品。
3. 填写标题、描述、分类、标签、价格、成色和交易方式。
4. 上传图片。
5. 提交审核。

### 4.2 处理订单

1. 进入我的订单或卖家订单列表。
2. 查看买家下单信息和订单中的商品图片、名称、金额。
3. 买家支付后确认或拒绝订单。
4. 与买家完成面交或柜机中转。
5. 订单完成后提交评价。

## 5. 管理员操作

### 5.1 商品审核

1. 登录管理员账号。
2. 进入后台商品审核页面。
3. 查看待审核商品。
4. 选择通过或拒绝，并填写拒绝原因。

### 5.2 举报处理

1. 进入举报处理页面。
2. 查看举报对象、原因和证据。
3. 根据情况选择驳回、下架商品、警告用户或封禁用户。
4. 处理结果写入举报动作记录。

### 5.3 用户管理

1. 进入用户管理页面。
2. 搜索目标用户。
3. 查看用户状态、信用分和违规记录。
4. 必要时执行禁言、封禁或解封操作。

## 6. 积分商城

1. 登录后进入积分页面。
2. 点击今日签到获得积分。
3. 查看任务列表和积分流水。
4. 在兑换区选择信用修复或商品曝光加速。
5. 商品曝光加速需要选择自己的上架商品。

## 7. 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 刷新后变成另一个登录用户 | 浏览器同一普通窗口共享 localStorage，请使用不同浏览器或不同无痕会话测试多用户 |
| 登录失败 | 确认数据库已初始化，演示账号密码是否正确 |
| 商品看不到 | 确认商品已通过管理员审核且状态为上架 |
| 后台打不开 | 确认登录账号有管理员角色 |
| MinIO 图片打不开 | 检查 MinIO 容器和端口 9000/9001 是否正常 |
