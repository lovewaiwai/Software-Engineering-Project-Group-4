# D-08 部署与运维手册

项目：SwapCampus 校园闲置物品交易平台  
版本：v1.0  
日期：2026-06-14

## 1. 环境要求

- Git
- Docker Desktop
- JDK 17 或更高版本
- Maven 3.9+
- Node.js 20+ 和 npm
- SQL Server Management Studio，简称 SSMS

## 2. 拉取代码

```powershell
git clone https://github.com/lovewaiwai/Software-Engineering-Project-Group-4.git
cd Software-Engineering-Project-Group-4
git switch main
```

## 3. 一键启动

启动数据库、对象存储、后端和前端：

```powershell
docker compose --profile app up -d --build
```

查看状态：

```powershell
docker compose --profile app ps
```

查看日志：

```powershell
docker compose --profile app logs -f backend frontend
```

停止服务：

```powershell
docker compose --profile app down
```

## 4. 只启动基础设施

如果后端和前端在本机运行，只启动 SQL Server、db-init 和 MinIO：

```powershell
docker compose up -d
```

后端本机运行：

```powershell
cd backend
mvn spring-boot:run
```

前端本机运行：

```powershell
cd frontend
npm install
npm run dev
```

## 5. 常用地址

```text
前端: http://localhost:5173
后端: http://localhost:8080
Swagger UI: http://localhost:8080/swagger-ui.html
MinIO 控制台: http://localhost:9001
MinIO 默认账号: minioadmin
MinIO 默认密码: minioadmin
WebSocket: ws://localhost:8080/ws/chat
```

## 6. 数据库连接

SSMS 连接 Docker 中 SQL Server：

```text
Server Name: localhost,1433
Authentication: SQL Server 身份验证
User Name: sa
Password: YourStrong!Passw0rd
Trust Server Certificate: 勾选
```

注意：SSMS 端口写法为 `localhost,1433`，中间是英文逗号。

## 7. 数据库初始化

`db-init` 默认会删除并重建 `SwapCampus` 数据库，再执行：

```text
db/migrations/*.sql
db/seeds/*.sql
```

手动重新初始化：

```powershell
docker compose up -d db-init
```

清空 Docker 数据卷：

```powershell
docker compose down -v
docker compose up -d
```

注意：`docker compose down -v` 会删除 SQL Server 和 MinIO 数据。

## 8. 环境变量

常用变量可通过 `.env` 或命令行覆盖：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DB_PORT` | `1433` | SQL Server 对外端口 |
| `DB_PASSWORD` | `YourStrong!Passw0rd` | SA 密码 |
| `BACKEND_PORT` | `8080` | 后端端口 |
| `FRONTEND_PORT` | `5173` | 前端端口 |
| `MINIO_API_PORT` | `9000` | MinIO API 端口 |
| `MINIO_CONSOLE_PORT` | `9001` | MinIO 控制台端口 |


## 10. 常见故障

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| SQL Server 启动慢 | 首次初始化耗时较长 | 等待健康检查完成后再看日志 |
| 1433 端口占用 | 本机已有 SQL Server | 在 `.env` 设置 `DB_PORT=11433` |
| 后端连不上数据库 | 端口或密码不一致 | 检查 `DB_URL`、`DB_PASSWORD` |
| 前端请求失败 | API 地址不对 | 检查 `VITE_API_BASE_URL` |
| 合并远端失败，提示 untracked files would be overwritten | 本地有未跟踪文件与远端同名 | 备份或删除该文件后再 pull |
| Docker 构建卡在 Maven 下载 | 网络或 Maven 源慢 | 等待或配置 Maven 镜像源 |
