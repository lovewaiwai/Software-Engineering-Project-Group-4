# D-06 软件测试计划与测试报告

项目：SwapCampus 校园闲置物品交易平台  
版本：v1.0  
日期：2026-06-14

## 1. 测试目标

- 验证用户、商品、订单、聊天、举报、积分等核心模块功能正确。
- 验证订单状态机、信用分、积分兑换等核心规则稳定。
- 验证前端 TypeScript 类型检查和生产构建通过。
- 验证 Docker Compose 配置可解析，支持一键部署。
- 为课程验收提供可复现的测试命令和结果记录。

## 2. 测试范围

| 模块 | 测试重点 |
| --- | --- |
| Auth/User | 注册登录、JWT、实名验证、用户状态 |
| Product | 商品发布、搜索、详情、收藏、审核 |
| Order | 下单、状态流转、商品锁定、取消、完成 |
| Payment | Mock 支付单、支付成功、退款预留 |
| Delivery | 面交确认、柜机中转预留 |
| Chat | 会话、消息、WebSocket 推送、未读数 |
| Report/Admin | 举报提交、处理动作、封禁、审核 |
| Credit/Points | 信用分流水、签到、兑换扣减、商品曝光加速 |
| Deployment | Docker Compose 配置、镜像构建、服务健康 |

## 4. 测试命令

后端单元测试：

```powershell
cd backend
mvn test
```

后端覆盖率报告：

```powershell
cd backend
mvn verify
```

前端构建：

```powershell
cd frontend
npm run build
```

Docker Compose 配置校验：

```powershell
docker compose --profile app config --quiet
```

全套 Docker 构建启动：

```powershell
docker compose --profile app up -d --build
```

## 7. 缺陷与风险

| 项目 | 当前状态 | 处理建议 |
| --- | --- | --- |
| 覆盖率不足 | 当前行覆盖率约 14.60% | 补充订单、商品、聊天、积分、举报等核心服务测试，目标提升至 60% 以上 |
| 接口测试集合 | 待补 | 使用 Postman/Apifox 补录主流程请求 |
| 性能测试 | 待补 | 使用 k6 或浏览器手工记录聊天和商品列表响应 |
| 灰度用户反馈 | 待补 | 至少邀请 3 名同学试用并记录问题 |

当前后端单元测试、前端构建和 Docker Compose 配置校验均已通过，基础质量门禁满足继续演示和归档条件。但 JaCoCo 行覆盖率约 14.60%，未达到选题指南 60% 目标，最终提交前应优先补充核心业务单元测试、接口测试集合和灰度用户反馈记录。
