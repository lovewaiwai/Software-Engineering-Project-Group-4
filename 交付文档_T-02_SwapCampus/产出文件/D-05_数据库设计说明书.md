# D-05 数据库设计说明书

项目：SwapCampus 校园闲置物品交易平台  
数据库：SQL Server 2022  
版本：v1.0  
日期：2026-06-14

## 1. 设计原则

- 主键使用 `BIGINT IDENTITY(1,1)`。
- 时间字段统一使用 `DATETIME2(0)`。
- 金额字段使用 `DECIMAL(10,2)`。
- 核心枚举字段使用字符串，便于答辩和调试。
- 演示库通过 `db-init` 每次重建，保证种子数据稳定。

## 2. 初始化机制

Docker Compose 中 `db-init` 服务会等待 SQL Server 健康后执行：

```text
db/migrations/*.sql
db/seeds/*.sql
```

当前结构脚本：

```text
db/migrations/V001__init.sql
db/migrations/V002__allow_product_draft_partial_fields.sql
db/migrations/V003__add_product_boosted_until.sql
```

当前种子脚本：

```text
db/seeds/V001__demo_accounts.sql
db/seeds/V001__task_c_demo_data.sql
db/seeds/V002__fix_duplicate_categories.sql
db/seeds/V003__expand_product_tags.sql
```

## 4. 关键表说明

### 4.1 users

| 字段 | 说明 |
| --- | --- |
| `id` | 用户 ID |
| `username` | 登录用户名 |
| `password_hash` | BCrypt 密码哈希 |
| `role` | `USER`、`PRODUCT_REVIEWER`、`SYS_ADMIN` |
| `status` | `ACTIVE`、`BANNED` 等 |
| `credit_score` | 信用分 |
| `point_balance` | 积分余额 |
| `created_at` / `updated_at` | 创建和更新时间 |

### 4.2 products

| 字段 | 说明 |
| --- | --- |
| `id` | 商品 ID |
| `seller_id` | 卖家 ID |
| `category_id` | 分类 ID |
| `title` / `description` | 标题与描述 |
| `price` | 价格 |
| `condition_level` | 成色 |
| `trade_modes` | 支持交易方式 |
| `status` | 商品状态 |
| `view_count` / `favorite_count` | 浏览和收藏数 |
| `boosted_until` | 商品曝光加速过期时间 |

### 4.3 orders

| 字段 | 说明 |
| --- | --- |
| `id` | 订单 ID |
| `order_no` | 订单编号 |
| `product_id` | 商品 ID |
| `buyer_id` / `seller_id` | 买家和卖家 |
| `amount` | 订单金额 |
| `status` | 订单状态 |
| `trade_mode` | 面交或柜机 |
| `completed_at` | 完成时间 |

### 4.4 credit_records

| 字段 | 说明 |
| --- | --- |
| `user_id` | 用户 ID |
| `delta` | 本次变动分值 |
| `score_after` | 变动后信用分 |
| `reason` | 变动原因 |
| `ref_type` / `ref_id` | 关联业务对象 |

### 4.5 point_records / point_redemptions

`point_records` 记录签到、任务、兑换等积分变化；`point_redemptions` 记录已兑换权益，包括信用修复和商品曝光加速。

## 5. 主要关系

```text
users 1 - 1 user_profiles
users 1 - N products
users 1 - N orders(buyer)
users 1 - N orders(seller)
products 1 - N product_images
products N - N tags
products 1 - N orders
orders 1 - N payments
orders 1 - N reviews
chat_sessions 1 - N chat_messages
reports 1 - N report_actions
users 1 - N credit_records
users 1 - N point_records
```

## 6. 索引设计

- 商品搜索索引：状态、分类、价格、创建时间。
- 商品曝光索引：`boosted_until`。
- 订单索引：买家、卖家、创建时间。
- 聊天索引：会话 ID、消息创建时间。
- 学号唯一索引：同一学号只能绑定一个账号。
