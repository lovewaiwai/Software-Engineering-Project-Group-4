## 1. 项目完成情况

本项目围绕 T-02 校园闲置物品交易平台选题，完成了从立项、需求分析、概要设计、详细设计、数据库设计、编码实现、测试、部署到答辩准备的主要工程过程。系统当前以 Vue 3 前端、Spring Boot 3 后端、SQL Server 数据库、MinIO 对象存储和 Docker Compose 部署为基础，支撑校园二手商品的发布、浏览、搜索、聊天、下单、评价、举报和后台治理。

## 3. 工程实践

项目采用模块化单体架构，后端按业务域拆分为 `auth`、`user`、`product`、`order`、`payment`、`delivery`、`chat`、`report`、`admin`、`points` 等模块。前端按页面、API、状态和组件拆分。支付、柜机、AI 使用 Adapter 模式，默认 Mock，实现了业务闭环和后续可扩展性的平衡。

数据库使用 SQL Server，迁移和种子脚本统一放在 `db/migrations` 和 `db/seeds`。Docker Compose 编排 SQL Server、MinIO、后端和前端，降低本地部署成本。GitHub Actions 提供后端测试、前端构建和 Docker 构建检查。
